# OpenStead

OpenStead is an independent fork of [AppFlowy Cloud](https://github.com/AppFlowy-IO/AppFlowy-Cloud), the Rust backend for the AppFlowy workspace platform. This repository builds on that upstream codebase and is maintained separately by the OpenStead community.

OpenStead is not affiliated with or supported by AppFlowy-IO. References to AppFlowy below describe the upstream project and its history.

## Project status

This fork is in active setup. Upstream deployment notes and links may describe AppFlowy-IO products and may not apply to OpenStead. Check this repository's compose files and configuration for the current deployment setup.

## Development

The backend is written in Rust. The repository includes Docker Compose configuration for development and deployment, along with application code under `src/`, `libs/`, and `services/`.
